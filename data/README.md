# Dados

`raw/imagens_nucleos` e `raw/imagens_proteinas` contêm os 43 pares de imagens de entrada.

`baseline/nucleos_preenchidos` contém as máscaras coloridas produzidas pelo método original. Elas são mantidas somente para reproduzir e comparar o resultado anterior; não participam da nova segmentação.

Os demais arquivos intermediários do repositório da iniciação científica não são necessários para executar o pipeline revisado.
